02 — Perakitan

Cara Merangkai Kabel LAN

Ikuti langkah berikut untuk membuat kabel LAN crossover.

01

Kupas Kabel UTP

Kupas bagian luar kabel UTP dengan hati-hati agar kabel inti di dalamnya tidak rusak.

02

Susun Kabel

Susun delapan kabel berdasarkan standar warna T568A dan T568B.

03

Potong Kabel

Ratakan ujung kabel menggunakan tang crimping agar panjangnya sama.

04

Masukkan ke RJ45

Masukkan seluruh kabel ke konektor RJ45 sesuai urutan warna.

05

Crimping

Masukkan RJ45 ke tang crimping lalu tekan hingga pin konektor mengunci kabel.

06

Test Kabel

Hubungkan kedua ujung kabel ke LAN tester. Pastikan indikator berjalan sesuai urutan.

04 — Peer to Peer

Menghubungkan 2 Laptop

Hubungkan dua laptop secara langsung menggunakan kabel LAN crossover.

🔗 Hubungkan Laptop

  • 01. Siapkan 2 laptop.
  • 02. Hubungkan kabel LAN crossover ke kedua laptop.
  • 03. Pastikan indikator Ethernet menyala.
  • 04. Atur IP Address pada kedua laptop.

⚙️ Pengaturan Windows

  • Control Panel
  • Network and Internet
  • Network and Sharing Center
  • Change adapter settings
  • Klik kanan Ethernet → Properties
  • Internet Protocol Version 4 (TCP/IPv4)

🌐 IP Address

Atur kedua laptop pada jaringan yang sama.

Perangkat IP Address Subnet Mask
Laptop 1 10.10.10.1 255.0.0.0
Laptop 2 10.10.10.2 255.0.0.0

💻 Tes Koneksi

Tekan Windows + R → ketik CMD → Enter. Kemudian jalankan:

ping 10.10.10.2

Jika muncul Reply from 10.10.10.2, berarti koneksi antar laptop berhasil.

05 — File Sharing

Sharing File Antar Laptop

Cara membagikan dokumen atau folder melalui jaringan LAN.

📁

1. Pilih Folder

Klik kanan folder yang ingin dibagikan, kemudian pilih Properties.

🔗

2. Aktifkan Sharing

Masuk ke tab Sharing → Advanced Sharing, lalu aktifkan Share this folder.

💻

3. Buka dari Laptop 2

Pada File Explorer laptop kedua, masukkan alamat berikut:

\\10.10.10.1

💡 Pastikan Ini Aktif

  • Network Discovery
  • File and Printer Sharing
  • Folder Sharing
  • Kedua laptop berada pada jaringan yang sama
